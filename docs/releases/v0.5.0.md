# MCP Hub v0.5.0

全面升级图形界面视觉设计与品牌识别度：为全部 14 款支持的 Agent 补齐真实官方品牌矢量图标，新增 6 套界面主题色调与浅色/深色双外观模式（合计 12 种视觉组合），在不改动原有三栏结构与操作流程的前提下大幅降低技术压迫感。配置库、备份与客户端文件格式不变，无需迁移。

## 本次变化

- **14 款 Agent 官方品牌图标**：内置纯矢量徽标（Claude Code、Claude Desktop、Codex CLI、WorkBuddy、Kimi Code、OpenCode、VS Code、Antigravity、Grok、Cursor、Cline、Gemini CLI、Windsurf、Trae），零运行时网络请求，支持在配置列表叠加头像组、右侧目标面板、Agents 页与预览差异弹窗中直观识别各客户端。
- **6 套界面主题色调 + 浅/深外观切换**：默认界面升级为清爽的「晴空蓝」，并内置「晴空蓝、星云紫、暖砂橙、松石绿、樱桃红、极简灰」6 套主题色，切换时同步联动页面底色、侧栏氛围、主按钮渐变、高亮态与悬浮变更坞。
- **双入口实时切换与本地记忆**：支持通过右上角顶栏调色盘菜单一键弹出切换，也可在「软件设置 → 外观与主题色」卡片中选择；偏好保存在本地前端存储，不影响 `settings.json` 结构与 IPC 契约。
- **排版与细节打磨**：优化中文字体栈与字号层级，收敛碎小字号，隐藏生硬的大写英文装饰眉标，重绘全部线性功能图标，升级柔和卡片阴影与底部悬浮变更坞。未新增或升级任何第三方依赖。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust 测试、前端单元测试与真实浏览器 E2E 回归、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。本版没有配置库或设置文件格式迁移。
需要回退时重新安装 v0.4.4 即可，配置库与历史备份完全兼容。
