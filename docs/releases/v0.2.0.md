# MCP Hub v0.2.0

正式 GUI 采用配置工作台布局，明确区分全局配置与项目配置，新增系统项目目录选择和软件设置持久化。

- 深色侧栏、浅色工作区和青绿色主操作；默认按 MCP 选择目标 Agent，也可按 Agent 选择 MCP。
  两种视角共用独立配对，保留高级矩阵、配置库编辑、差异预览和回滚入口。
- 全局配置只应用到勾选的 Agent，隐藏项目目录，后端清空项目上下文。
- 项目配置必须明确选择存在的绝对目录。Windows / macOS 调用系统目录对话框，支持手动输入、取消和中文路径。
  检测、查看已有配置、预览和应用使用同一目录；不会回退到软件启动目录，保留 Windows 规范路径和 UNC 前缀。
- 软件全局设置保存默认配置库、备份目录、启动默认范围、默认写入策略和上次项目目录。
  重启后恢复，设置文件损坏时明确报告错误并阻止配置操作，原文不会静默覆盖。
- 首次启动可直接新建空配置库，不必手工创建 YAML。Agent 页保留脱敏只读查看，未加载配置库也可使用。
- 本版包含此前 dev 分支的安全修复：共用物理文件的计划合并和冲突阻止、独占备份目录、回滚失败与审计失败单独提示、
  预写入基线检查、配置库安全保存、隐藏完整文件中的敏感差异、VS Code 按实际文件使用对应格式和根节点。

## 下载与使用

| 产物 | 用途 |
|---|---|
| `MCP.Hub_0.2.0_x64-setup.exe` | Windows x64 GUI 安装程序，推荐 Windows 用户下载 |
| `MCP.Hub_0.2.0_aarch64.dmg` | macOS Apple Silicon GUI |
| `mcp-hub-v0.2.0-windows-x64.zip` | Windows CLI，解压后在终端运行 |
| `mcp-hub-v0.2.0-macos-arm64.tar.gz` | macOS Apple Silicon CLI |
| `mcp-hub-v0.2.0-linux-x64.tar.gz` | Linux x64 静态 CLI |
| `customer-mcp.yaml` | 示例配置库，使用前按自己的环境调整 |
| `SHA256SUMS` | 上述 6 个文件的 SHA-256 校验清单 |

Windows 关闭旧版后运行安装程序。CLI 压缩包不包含 GUI，不要双击 CLI 当作桌面软件使用。
安装包未签名；macOS 首次打开可能需要右键选择「打开」。

第一次使用：加载自己的 YAML 绝对路径或新建空配置库 → 在 MCP配置页编辑并保存 →
选择全局或项目范围 → 项目范围选择目录 → 工作台逐项勾选 → 预览实际文件路径 → 确认写入。
范围跟随顶部的条目使用 inherit；明确限定 user/project 的条目只在相应范围出现。
已有 Agent 的配置可在 Agent 页只读查看，本版不自动转换导入，也不复制脱敏占位符到配置库。

## 持久化与备份

设置位于 `~/.mcp-hub/settings.json`，Windows 通常为当前用户目录下的 `.mcp-hub`。
设置保存先备份原文，再原子写入和校验。默认配置库、范围、写入策略在下次启动使用；保存不会自动切换当前工作范围。
目录选择立即记住最近项目。新备份目录用于后续配置写入，不迁移旧备份；切回旧目录即可查看原历史。
设置文件自身的备份固定保留在 `~/.mcp-hub/backups`，审计日志仍在用户数据目录。
备份含原始配置，可能包含凭据。Windows 权限沿用用户目录 ACL，不声称已自动加固。

## 验证与限制

所有测试和构建均在 GitHub Actions 执行：Windows/Linux Rust 测试、前端选择与 IPC 测试、Chrome 真实页面回归、
Windows 桌面编译及目录选择命令构造测试、发布恢复测试、三平台 CLI 冒烟与 Windows/macOS 安装包构建。
设置测试在隔离目录验证重启恢复、原文备份、非法设置不覆盖、损坏数据失败关闭、项目隔离、自定义备份目录与空库创建。
浏览器使用模拟 IPC 验证逐对勾选、过期响应、项目参数、全局无项目参数、取消目录选择、保存失败与重启恢复。
系统对话框的人机交互未由无桌面 CI 自动操作；如对话框不可用，可手动输入项目绝对目录。

写入成功表示配置落盘，连接状态、OAuth 和服务运行仍需在目标 Agent 中验证。
预览到确认之间仍会重新计算配置，尚未绑定原清单内容快照；请避免在预览后由其他程序编辑清单。
基线检查也不等于跨进程文件锁。参数/环境变量的编辑器仍沿用旧版，含逗号的复杂值宜直接编辑 YAML。

Windows 可用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 与 SHA256SUMS 比较；
Linux/macOS 可用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 回退

关闭 MCP Hub 并重新安装 v0.1.1，保留自己的配置库和用户数据目录。本版新增设置文件，不迁移原 Agent 配置格式；
旧版不使用新软件设置，也不会自动移动自定义备份。回退软件前需要恢复 Agent 配置时，在「变更记录」核对记录后回滚。
回滚会覆盖相应文件的当前内容，先另存后续编辑。设置故障可从默认 backups 中找到 settings 原文备份，关闭软件后核对恢复。
