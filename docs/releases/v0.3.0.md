# MCP Hub v0.3.0

新增从 Agent 已有 MCP 配置安全导入统一配置库的 GUI 流程，处理同名冲突、敏感字段和预览一致性。

- Agent 页「查看 MCP → 导入配置库…」进入扫描、逐项选择、差异预览和确认保存。目标配置库尚不存在时确认后新建。
- 同名条目默认跳过，可重命名新增或明确替换同名项；批次内目标名必须唯一。
  替换需要额外确认，会替换整条配置（包括原平台覆盖），保留未选中的条目，并先备份原配置库。
- 来源原文和凭据不回传前端。隐藏字段需映射到环境变量名；已有完整变量引用保留或归一化，不在导入时展开变量值。
- 无法无损转换的字段、类型错误、歧义别名、多个认证来源和非 Bearer 认证会阻止对应条目导入，避免静默丢字段。
- 确认使用后端保存的预览，检查来源内容、候选路径、配置库原文、项目上下文和软件设置，变化后必须重新扫描。
  新预览使旧预览失效，确认仅能提交一次；取消、空选择和全部跳过不保存配置库。
- 导入只修改统一配置库，来源 Agent 文件不变。目标不能使用其他已知 Agent 配置路径、软件设置或审计日志，
  包括当前项目的候选文件、空文件及尚未创建的已知路径。显示导入成功不表示 MCP 已连接或已经分发到目标 Agent。
- 导入面板、预览和提交错误会自动定位到可视区，便于在长 Agent 列表中继续操作。

## 导入步骤与敏感信息

1. 加载目标配置库的绝对路径，选择全局或项目范围；项目范围先选择存在的项目目录。
2. Agent 页点击「查看 MCP」，核对实际来源文件，再点击「导入配置库…」。
3. 勾选条目，处理同名项，为隐藏字段填写环境变量名（例如 `SERVICE_API_KEY`），不要填写密钥值。
4. 点击「预览导入」，核对新名称、变量引用和替换内容；有整条替换时勾选额外确认，再确认导入。
5. 导入完成后可在工作台选目标 Agent，另行预览并分发；导入本身不会改写来源或其他 Agent。

地址可能含凭据、参数可能携带密钥，因此公共 URL、包名、工作目录和非白名单命令也可能要求变量映射。
Bearer 映射写为 `auth.token_env`，其他隐藏值写为 `${ENV:VARIABLE_NAME}`；仅保留少量固定命令和参数。
需自行在 MCP 的运行环境配置变量值。导入不会创建环境变量、获取 OAuth、启动服务或执行连接验证。
导入条目保留来源 user/project 范围，不自动改为 inherit。已有软件全局设置和最近项目目录继续沿用 v0.2.0 的设置文件。
完整字段规则及边界见 [导入说明](https://github.com/rshun/mcpconfig/blob/v0.3.0/docs/IMPORTING.md)。

## GitHub 验证与限制

所有测试和构建均在 GitHub Actions 执行，本地未安装依赖、运行测试或构建。
发布候选包含 Windows/Linux Rust 测试、前端 IPC 测试、Chrome 真实页面回归、Windows 桌面编译和原生命令测试、
发布恢复测试、三平台 CLI 冒烟及 Windows/macOS GUI 安装包构建。校验通过后才为该提交打标签，并发布同一批已验证产物。

导入后端测试在隔离目录使用占位符，覆盖三平台 14 个适配器、JSON/JSONC/TOML、同名冲突、敏感值隐藏、
变量引用、非法输入、未选中项、原文备份、来源与配置库变化、取消、重复确认、已知 Agent 路径保护和保存失败。
浏览器使用模拟 IPC 验证交互和参数；真实磁盘操作由 Rust 测试验证。配置导入和配置分发是独立操作。

草稿有效期 10 分钟，最多同时保留 8 份，每个输入文件限 4 MiB。不提供跨进程文件锁，请避免确认期间由其他软件同时改写文件。
分发流程仍保留 v0.2.0 的限制：预览后确认时会重新计算配置，尚未绑定原清单内容快照；该限制不适用于本版新增的导入预览。
目录选择器的人机交互未由无桌面 CI 自动操作，可使用手动绝对路径。含逗号的复杂参数或环境变量值仍建议直接编辑 YAML。

下载后可用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 与清单比较；
Linux/macOS 可执行 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 回退

关闭 MCP Hub 后重新安装 v0.2.0，保留配置库、`~/.mcp-hub` 和自定义备份目录。本版没有引入配置库或软件设置格式迁移。
需要撤销导入时，在「变更记录」核对配置库路径，选择导入前的备份回滚；回滚会覆盖该文件的后续编辑，先另存这些编辑。
如果导入前配置库不存在，回滚将撤销新文件。来源 Agent 配置未被导入功能修改，不需要为导入操作回滚来源文件。
备份可能包含原配置库中的历史凭据，请妥善保管。审计失败可能发生在配置库已经保存之后，应先核对结果再决定是否重试。
