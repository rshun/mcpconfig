# MCP Hub v0.1.1

新增只读查看本机 Agent 已有 MCP 配置的功能，并修复 JSON/JSONC 中文解析。

- 在「环境检测」页，点击目标 Agent 一行的「查看 MCP」，展开条目查看配置字段结构。
- 显示实际来源路径、文件格式和 MCP 名称；没有创建或加载清单文件时也可使用。
- 区分配置文件不存在、没有 MCP 条目、格式或容器结构损坏，不会把错误误报为空配置。
- 支持项目已有的 14 个客户端适配器，读取 JSON、JSONC、TOML 及 TOML 内联表，处理 UTF-8 BOM。
- 读取候选文件时按实际扩展名解析；优先文件损坏时报告错误，不会静默改读其他候选。
- 敏感值在后端隐藏：环境变量、headers、参数、URL、自定义字段的值不返回前端。
  可执行文件路径、已知传输类型和启用开关在符合展示规则时保留。
- 切换 Agent、刷新或切换作用域后，旧请求不会覆盖当前查看结果。
- 修复 JSON/JSONC 的中文和 emoji 在去除注释、尾逗号时发生乱码的问题。

## 下载与使用

| 产物 | 用途 |
|---|---|
| `MCP.Hub_0.1.1_x64-setup.exe` | Windows x64 图形界面，安装后从「环境检测」进入新功能 |
| `MCP.Hub_0.1.1_aarch64.dmg` | macOS Apple Silicon 图形界面 |
| `mcp-hub-v0.1.1-windows-x64.zip` | Windows x64 命令行版，需在终端运行，不提供 GUI |
| `mcp-hub-v0.1.1-macos-arm64.tar.gz` | macOS Apple Silicon 命令行版 |
| `mcp-hub-v0.1.1-linux-x64.tar.gz` | Linux x64 静态命令行版 |
| `customer-mcp.yaml` | 示例清单，使用前按实际环境调整 |
| `SHA256SUMS` | 以上下载文件的 SHA-256 校验清单 |

Windows 请关闭正在运行的旧版 MCP Hub，再运行新版安装程序。安装包未签名，系统可能提示安全警告；
macOS 首次打开可能需要右键选择「打开」。CLI 压缩包解压后在终端运行 `mcp-hub --help`，不要双击当作 GUI 使用。

新功能只读，不会修改 Agent 配置、导入统一清单、生成备份或启动 MCP 服务。
脱敏详情用于查看，不用于直接复制配置。项目级目录沿用应用启动时的工作目录，请核对展示的来源路径；
不支持的作用域不可读取。候选路径沿用项目内置规则，不代表客户端运行时加载的全部配置层。

分发配置仍按「加载清单 → 勾选目标 → 生成差异预览 → 确认写入」操作。
GUI 顶部清单输入框需填写自有清单或下载示例的绝对路径。配置写入成功不等于 MCP 已连接，
连接状态、OAuth 登录和服务运行需要在目标 Agent 中验证。

## 验证与回退

发布验证全部在 GitHub Actions 执行：Windows/Linux 各 111 项 Rust 测试、7 项前端测试、
1 项真实浏览器回归、6 项发布恢复测试、前端构建及 Windows 桌面编译检查。
后端测试使用隔离临时目录覆盖三平台 14 个适配器、来源优先级、中文、错误和敏感值处理；
浏览器回归覆盖只读查看、错误提示、缺少清单和异步响应顺序。
发布构建另执行三平台 CLI 冒烟检查、Linux 静态链接检查、Windows/macOS 安装包构建和 SHA-256 校验。

下载后可在 Linux/macOS 执行 `sha256sum --check SHA256SUMS`；macOS 也可执行 `shasum -a 256 -c SHA256SUMS`。
Windows 使用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 与清单比较。

版本回退可重新安装上一版本，保留自己的清单和数据目录；此版本未引入数据格式迁移。
若已通过分发功能改写 Agent 配置，可在「备份回滚」选择写入前记录恢复。只读查看本身不产生配置变更。
