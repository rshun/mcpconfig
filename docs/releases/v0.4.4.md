# MCP Hub v0.4.4

从 Agent 导入配置库时，识别到的凭据不再必须映射为环境变量：默认按原值复制，也可逐个字段改为环境变量映射。扫描和预览中凭据保持隐藏；配置库格式不变，无需迁移。

## 本次变化

- 导入页每个凭据字段新增「原样复制 / 映射环境变量」选项，默认「原样复制」，无需填写即可导入。
- 原样复制写入来源原值：Bearer 写为 `auth.token`，URL、参数（如 `--token=value` 整体）、环境变量和请求头保留原文。
- 原值只在后端内存中保存，不经过 IPC 返回前端；扫描结果和导入预览只显示 `[已隐藏]`，审计日志不记录凭据值。
- 同一条目可混用两种方式；每个凭据字段必须且只能选择一种，未知字段或普通字段不能借“原样复制”绕过校验，校验失败不写入任何文件。
- 选择「映射环境变量」时行为与 v0.4.3 相同，写入 `${ENV:NAME}` 或 `auth.token_env`。
- 已有配置查看和分发差异的脱敏规则不变。未新增或升级依赖。

## 注意

原样复制的凭据会以**明文**保存在配置库及写入前备份中。请勿将配置库提交到代码仓库或分享给他人；需要共享配置库时改用「映射环境变量」。
配置库校验对明文 `auth.token` 给出建议改用 `token_env` 的提示，不阻止保存。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust（含原样复制写入原值、预览隐藏、混用与字段校验回归）、前端测试与浏览器回归（含凭据处理方式默认原样复制、切换为环境变量映射及提交内容核对）、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。本版没有格式迁移。
需要回退时重新安装 v0.4.3；已原样复制到配置库的明文凭据会保留，旧版可以正常读取。如需改为变量引用，可在配置库中编辑对应条目或从「变更历史」恢复导入前的备份。
