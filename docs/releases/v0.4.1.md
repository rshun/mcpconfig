# MCP Hub v0.4.1

修复 GUI 分发预览与确认写入的一致性，新增 Windows x64 GUI 免安装 ZIP。配置库和软件设置不迁移格式。

## 分发一致性修复

- 后端保存原始预览计划，前端只获得一次性预览 ID 和脱敏信息。确认时校验完整配置库、目标原文与存在状态、实际路径及候选优先级、上下文、软件设置、备份位置和最终解析计划。
- 发现配置、路径、变量或设置变化时，整批拒绝确认，不产生该次写入、备份或审计，要求重新预览。检查覆盖本次计划中未变化或已阻止的目标。
- 真正写入使用后端缓存的原预览计划，不把确认时重算的内容直接写入；原有 IO 基线检查继续保留。
- 新预览、取消、过期或确认尝试会使旧 ID 失效，重复确认不可再次写入。预览有效期 10 分钟，配置库、设置和目标单文件上限 4 MiB。
- 失败原因在预览弹窗内展示，旧确认按钮会移除，重新预览后才可继续。快照原文和凭据不写入前端、日志或草稿文件。
- 旧版不带预览 ID 的确认 IPC 被拒绝，前后端需配套更新。CLI 保留原有即时计划与应用语义。

## Windows 免安装版

将整个 GUI ZIP 解压到新目录，打开其中版本目录里的 `MCP.Hub.exe`。包内附中文 `README.txt` 和示例配置。
它与安装程序使用同一 GitHub 构建生成的 GUI 二进制；ZIP 打包校验 x64 PE 图形子系统、包内文件集合、CRC 和原二进制字节，避免误装 CLI。

应用使用系统已有的 [Microsoft WebView2 Runtime](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。
若缺少运行时，请从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 获取 Evergreen x64 Runtime 后启动。
ZIP 不自动下载运行时；免安装指无需安装 MCP Hub，本版不打包固定版浏览器运行时。

配置、设置和备份继续保存在当前用户的 `.mcp-hub` 及自定义位置，不随 ZIP 目录移动；安装版与 ZIP 版共用这些数据。
切换版本前先关闭已运行的 MCP Hub，避免同时启动多个版本。安装包和免安装二进制未签名，请核对来源与校验值。

## 验证、限制与发布来源

测试和构建全部在 GitHub Actions：Windows/Linux Rust、前端测试与浏览器回归、Windows 桌面编译和原生 DTO 脱敏测试、
发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 安装包构建、Windows GUI ZIP 内容校验、最终资产集合与 SHA256SUMS 校验。
本地不安装依赖、不运行测试或构建。ZIP 校验检查包结构与二进制类型，不等同于目标电脑上的安装后运行或真实 MCP 连接验证。

检查通过后通过 PR 合入 master，再对已进入 master 历史、与主干文件树一致的候选提交创建标签，发布同一批已验证产物。
旧版资产集合仍可恢复发布，v0.4.1 起资产校验要求包含 GUI 免安装 ZIP。

不提供跨进程文件锁或跨文件原子事务。复核后、逐文件写入期间的外部竞争仍由 IO 检查处理，可能出现部分写入或逐文件阻止。
请避免其他软件同时改写配置。完整范围见 [一致性说明](https://github.com/rshun/mcpconfig/blob/v0.4.1/docs/SAFETY.md#分发预览与确认一致性)。

下载后可用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 与清单比较；
Linux/macOS 可用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版，或将 GUI ZIP 解压到新目录运行。保留原配置库、`~/.mcp-hub` 和自定义备份目录，本版没有格式迁移。
回退时关闭程序，运行旧目录或重新安装 v0.4.0；该版本不含本次预览一致性保护。
如需回退配置内容，在“变更历史”核对备份文件，先另存后续编辑，再明确确认恢复。备份可能包含原始凭据，请妥善保管。
