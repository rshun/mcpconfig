# MCP Hub v0.6.0

完成核心架构与安全边界升级：重构变量与凭据求值流水线（防止项目级配置内联宿主密钥）、引入零密钥三方合并基线与客户端扩展字段无损透传、收口配置库 IPC 凭据脱敏与 CAS 乐观并发控制、实现 JSONC 词法区间补丁（保留注释与原缩进）、解锁 Claude Code 本地作用域，并支持通过 `~/.mcp-hub/adapters.yaml` 声明自定义 Agent 适配器。既有 `catalog.yaml` 与客户端配置向后兼容，无需手动迁移。

## 本次变化

- **变量与密钥求值流水线升级**：分离路径宏（`${HOME}` / `${PROJECT_ROOT}`）与环境变量引用（`${ENV:VAR}`）。项目级作用域（`Scope::Project`）不再内联宿主环境变量明文，而是自动翻译为目标客户端原生语法（`${VAR}` / `{env:VAR}` / `${env:VAR}`）；对仅支持字面量的客户端，缺失凭据或处于项目级时自动阻断写入，严禁哨兵占位符落盘。
- **零密钥三方合并（3-Way Merge）与扩展透传**：新增 `~/.mcp-hub/managed-state.json` 仅记录已托管键名骨架（零标量、零密钥落盘），在 `Merge` 模式下支持精准移除已从清单删除的键而完整保留用户手写字段，并同步修复矩阵漂移检测删键漏报；支持客户端安全扩展字段（`alwaysAllow`、`autoApprove`、`disabledTools`、`tool_timeout_sec`）按客户端命名空间无损导入与回写。
- **配置库 IPC 脱敏与 CAS 乐观并发**：桌面端 `load_catalog` 默认隐藏敏感字面值并返回修订号 `revisionId`，原始凭据仅驻留 Rust 内存；`save_catalog` 校验修订号与磁盘原文快照防止覆盖外部并发修改，并在后端自动回填未改动的隐藏凭据（支持条目重命名映射）。
- **强类型传输模型、自定义请求头认证与平台覆盖**：提供校验合一的 `TransportSpec` 强类型视图；新增 `Auth::Header`（`type: header` / `api_key`，支持自定义请求头与前缀）；`overrides` 补全按操作系统覆盖 `auth`、`timeout_seconds` 与 `enabled`。
- **JSONC 区间无损补丁、Claude Code 本地作用域与 YAML 文档**：零新增外部依赖实现 JSONC 词法区间替换（Span Patching），保留文件非覆盖区注释、尾随逗号与原缩进，并在预览弹窗提供内部注释剥离确认开关；支持 `#fragment` 动态嵌套容器路径，打通 Claude Code 本地级配置（`~/.claude.json` 内 `projects.<项目路径>.mcpServers`）；`ConfigDoc` 新增 `YAML` 格式支持。
- **声明式自定义适配器（`adapters.yaml`）**：解耦适配器静态生命周期限制，支持在 `~/.mcp-hub/adapters.yaml` 声明兼容的新客户端（含 ID 校验、冲突拦截与路径穿越防护），无需重新编译发版即可接入探测、预览、分发与备份闭环。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust 测试、前端单元测试与真实浏览器 E2E 回归、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。既有 `catalog.yaml` 与 `settings.json` 无需迁移，`managed-state.json` 将在首次分发写入后自动建立键名骨架基线。
需要回退时重新安装 v0.5.0 即可；若使用了 v0.6.0 新增的 `type: header` 认证、`extensions` 或新增 `overrides` 字段，回退到旧版前请先从 `catalog.yaml` 移除对应新字段。
