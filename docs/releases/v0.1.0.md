# MCP Hub v0.1.0

首个版本：使用一份自维护 YAML 清单，为 14 个 MCP 客户端生成各自的原生配置。

- 支持 Windows、Linux、macOS 平台覆盖、环境变量插值和客户端作用域。
- 提供 CLI 检测、差异预览、应用、备份查询与回滚。
- 提供 Windows/macOS 桌面 GUI：配置矩阵、清单编辑、差异预览、环境检测、备份回滚。
- GUI 按「客户端 → 选中 MCP」精确分发；空选择不写入，未选中条目保留。
- 确认写入沿用预览时的选择，改变勾选或覆盖模式会使旧预览失效。
- 配置写入包含备份、写后解析校验和审计记录。

发布前在 GitHub Actions 完成 Windows/Linux 各 104 项 Rust 测试、6 项前端测试、
1 项真实浏览器回归测试、前端构建和 Windows 桌面编译检查。
CLI 发布构建另执行 `--version`、`clients` 冒烟检查；Linux CLI 验证为 musl 静态链接。

## 使用与限制

- 桌面包未签名；macOS 首次打开可能需要右键选择「打开」。
- GUI 默认清单路径是仓库相对路径。安装后请下载示例清单或准备自有 YAML，
  在顶部清单输入框填写其绝对路径，再点击「加载」；根据实际环境修改示例路径和环境变量名称。
- 配置成功不等于 MCP 服务已经连通；OAuth 登录和服务运行仍由对应客户端负责。
- 不支持环境变量引用的客户端可能生成「需内联」占位符，需要按实际客户端能力处理。
- Claude Code 的 local 作用域暂不支持；跨机器 Bundle 导出尚未实现。
- 应用配置前先查看逐文件差异。配置回退使用 GUI「备份回滚」或 `mcp-hub restore --id <backup-id>`。
- 标签发布复用同一提交已验证的产物；发布流程不会自动应用用户的 MCP 配置。

校验下载文件：Linux/macOS 可在下载目录运行 `sha256sum --check SHA256SUMS`；
macOS 未提供 `sha256sum` 时可用 `shasum -a 256 -c SHA256SUMS`。
Windows 可用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 与 `SHA256SUMS` 对照。
