# MCP Hub v0.7.3

本版重点优化从已有 Agent 导入配置库时的真实方言兼容性与分级降级体验，并微调精工微立体（Tactile 3D）视觉厚度与补充英文文档；既有 `catalog.yaml`、`settings.json` 与客户端配置 100% 向后兼容。

## 本次变化

- **Agent 导入分级校验与专有字段兼容**：对不含疑似敏感凭据的客户端专有扩展字段（如 Codex `tools` 工具审批策略），不再一刀切锁死无法导入，而是在扫码与差异预览页面明确提示「将仅导入核心连接配置，忽略客户端专有字段：…」，让用户知情勾选；结构异常、别名歧义、未适配认证头及含疑似凭据的未知字段继续严格阻止。
- **Codex / WorkBuddy / Cline 核心方言补齐**：`AdapterSpec` 支持自定义请求头键名，Codex CLI 双向映射 `http_headers` ↔ `headers`（导入与分发均对齐）；WorkBuddy 与 Cline 启用 `disabled` 启停字段双向转换；通用解码器支持导入 `description` 描述字段并纳入敏感信息保护管线。
- **精工微立体（Tactile 3D）视觉调薄**：将常规/主/次/危险按钮、切库按钮、导航项、分段开关、主题/字体/质感卡片、矩阵单元格与下拉框的立体底边厚度收敛至 `1px–1.5px`，同步调轻外投影、内凹槽与悬停/按压位移幅度，界面更轻盈克制；保留「立体 3D / 简约扁平」一键切换。
- **双语文档补充**：`README.md` 顶部新增语言切换入口并在文末添加完整 `English Guide`，同步更新 [`docs/IMPORTING.md`](../IMPORTING.md) 与 [`docs/adapters.md`](../adapters.md)。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust 测试、前端单元测试与真实浏览器 E2E 回归、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。既有 `catalog.yaml`、`settings.json` 与 `managed-state.json` 无需迁移，直接兼容使用。
需要回退时重新安装 v0.7.2 即可。
