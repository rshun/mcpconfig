# MCP Hub v0.7.1

本版升级前端字体与排版体验：默认采用「**温润文楷**」（现代西文无衬线搭配霞鹜文楷屏幕阅读版，未安装时自动回退至优化后的现代黑体栈），支持在右上角调色盘与「软件设置 → 外观与字体」一键切换「温润文楷 / 现代黑体」并记住偏好，同时优化字重层级、行高字距与等宽代码防连字表现。零新增依赖、零安装包体积增量，既有 `catalog.yaml`、`settings.json` 与客户端配置 100% 向后兼容。

## 本次变化

- **默认「温润文楷」与现代西文混排**：重排西文与中文字体回退链，英文与数字优先使用 `Plus Jakarta Sans` / `Inter` / `SF Pro Text` / `Segoe UI Variable` / `Segoe UI` 等现代无衬线字体，中文优先命中本机「霞鹜文楷 屏幕阅读版（`LXGW WenKai Screen`）」，未安装该字体时优雅回退至 `PingFang SC` / `HarmonyOS Sans SC` / `MiSans` / `Noto Sans SC` / `Source Han Sans SC` / `Microsoft YaHei UI`。
- **双入口实时字体切换与持久化**：在右上角调色盘弹出层「外观模式」下方及「软件设置 → 外观与字体」面板新增「温润文楷 / 现代黑体」切换（附 `Aa文` / `Aa黑` 样本预览），支持 `localStorage`（`mcp-hub-font`）自动记住偏好及 URL 参数 `?font=wenkai|sans` 覆盖。
- **排版层级与等宽代码细节打磨**：针对 `LXGW WenKai Screen` 单字重特性将 `font-synthesis` 调整为 `weight` 以保持标题、侧栏选中态与按钮加粗层级；在文楷模式下采用 `14.5px` 基准字号、`1.7` 行高与标题/说明文字微调字距；等宽区域（`--mono`）优先匹配 `JetBrains Mono` / `Cascadia Code` 并禁用连字（`font-variant-ligatures: none`），防止命令行 `--`、`->` 变形。
- **字体测试与端到端回归**：新增 `FONT_PRESETS` / `readInitialFont` 单元测试及真实浏览器字体切换、持久化与窄屏无溢出回归断言。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust 测试、前端单元测试与真实浏览器 E2E 回归、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。既有 `catalog.yaml`、`settings.json` 与 `managed-state.json` 无需迁移，直接兼容使用。
需要回退时重新安装 v0.7.0 即可。
