# MCP Hub v0.7.2

本版带来「**精工微立体按键（Tactile 3D）**」交互视觉升级：为全局核心按钮与交互控件赋予顶部细腻高光、实体立体底边与按压下沉手感，并支持在右上角调色盘与「软件设置 → 外观与样式」一键切换「立体 3D / 简约扁平」。纯 CSS 实现，零新增依赖、零安装包体积增量，既有 `catalog.yaml`、`settings.json` 与客户端配置 100% 向后兼容。

## 本次变化

- **核心按钮与交互控件 Tactile 3D 化**：覆盖主/次/危险按钮、小号按钮、顶栏图标按钮悬停与激活态、品牌方块、侧栏切库按钮、当前导航项、内凹滑槽＋凸起滑块的分段筛选器与模式开关、内凹轨道＋微球滑块的拨动开关，以及主题色调/字体/质感卡片、Agent 卡片、矩阵单元格与下拉选择器；输入框、文本域与主列表保持清爽扁平。
- **6 套浅/深色调专属光影适配**：为浅色与深色模式下的 `ocean`、`violet`、`amber`、`emerald`、`rose`、`slate` 主题（含深色极简灰亮底深字主按钮特例）配置专属 `--accent-edge` 与立体高光投影变量；全部立体底边通过 `box-shadow` 与 `transform: translateY(...)` 实现，不改写边框宽度，避免按压抖动与小屏布局重排。
- **「立体 3D / 简约扁平」双入口切换与持久化**：默认启用 `3d`，在右上角调色盘弹出层及「软件设置 → 外观与样式」面板提供带实时预览胶囊的切换开关，通过 `localStorage`（`mcp-hub-style`）自动记住偏好，并支持 `?style=3d|flat` URL 参数覆盖。
- **单元测试与真实浏览器回归**：新增 `SURFACE_STYLE_PRESETS` / `readInitialSurfaceStyle` 单元测试及 Chrome E2E 3D/扁平切换持久化与窄屏/小桌面无溢出回归验证。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust 测试、前端单元测试与真实浏览器 E2E 回归、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。既有 `catalog.yaml`、`settings.json` 与 `managed-state.json` 无需迁移，直接兼容使用。
需要回退时重新安装 v0.7.1 即可。
