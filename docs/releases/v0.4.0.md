# MCP Hub v0.4.0

正式 GUI 改为“配置库优先”：维护一份 MCP 库，选择目标 Agent，预览后确认写入。配置格式与软件设置沿用 v0.3.0。

## 界面与操作

- 默认首页「我的 MCP」，侧栏提供「我的 MCP / Agents / 变更历史」，底部独立进入「软件设置」。统一浅色布局、线性图标和间距，支持小窗口。
- MCP 库显示所有条目；切换全局或项目范围时，不匹配的配置保留并说明原因。全局配置隐藏项目目录；项目配置可选择系统目录或手动填写绝对路径。
- 点「选择目标」打开配置详情，各 MCP 独立勾选目标 Agent。底栏显示本次选择，进入逐文件预览后再确认写入；批量矩阵保留为高级入口。
- 添加、编辑、目录选择、导入和预览使用独立对话框，限制背景焦点。未保存编辑在关闭、Escape 或切页时要求确认放弃；写入时锁定上下文。
- 首次使用无配置库时显示导入或手动添加引导，首次保存时才创建文件；已有损坏文件会报错，不会当作空库覆盖。
- 参数逐项、环境变量和请求头逐行编辑，保留逗号、等号、空格和空参数；字面值默认遮掩。已有平台覆盖、标签、启用状态和超时字段继续保留。
- Agents 页面点选 Agent 查看已有配置，独立导入流程保留同名跳过、重命名、替换确认和敏感字段环境变量映射。导入完成自动返回配置库，来源 Agent 文件不变。
- 软件设置持久化默认配置库、备份目录、启动范围、写入策略和最近项目；与当前任务范围独立。保存只显示一条结果提示。
- 变更历史区分成功、部分失败、回滚失败和审计异常。恢复备份需明确确认，进行中禁用重复恢复与导航。

## 快速使用

1. 在「我的 MCP」从已有 Agent 导入，或手动添加；侧栏「当前配置库」可切换现有库或指定新位置。
2. 选择全局或项目范围。项目范围先选择已经存在的目录；取消选择不保存设置，不沿用软件启动目录。
3. 点配置的「选择目标」，勾选需要应用的 Agent。保存到配置库不会自动分发。
4. 点「预览变更」，核对实际路径、共享文件影响和脱敏差异，再确认写入。配置写入成功不代表 MCP 已连接。
5. 在「软件设置」管理启动默认值，在「变更历史」核对结果与备份。

完整规则见 [界面说明](https://github.com/rshun/mcpconfig/blob/v0.4.0/docs/UI-DIRECTION.md) 和 [导入说明](https://github.com/rshun/mcpconfig/blob/v0.4.0/docs/IMPORTING.md)。

## GitHub 验证与限制

所有测试和构建均在 GitHub Actions，本地不安装依赖、不运行测试或构建。发布候选包含 Windows/Linux Rust 测试、
前端单元测试及构建、Chrome 真实页面交互、Windows 桌面编译及原生命令测试、发布恢复测试、三平台 CLI 冒烟，以及 Windows/macOS GUI 安装包构建。
独立 macOS Chrome 回归提供带中文字体的截图；浏览器使用内存 IPC 数据，真实磁盘规则由隔离目录的 Rust 测试验证。

通过 PR 合入 master 后，标签指向已进入 master 历史的同一 dev 发布候选提交，复用其已验证的构建产物；校验资产后发布。
原生目录对话框的人机操作、安装后运行和真实 MCP 连接仍需目标环境核对。

分发确认仍重新计算配置，未绑定预览时的配置库内容快照；请避免预览和确认期间由其他软件并发修改文件。
导入沿用源/目标快照和一次性预览校验，但不提供跨进程文件锁。已有高级字段会保留，本轮未新增全部高级字段的可视化编辑。
变量值和连接状态不会在编辑器验证；需自行为目标 MCP 的运行环境配置变量。

下载后在 Windows 使用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 与清单比较；
Linux/macOS 可用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 回退

关闭 MCP Hub 后重新安装 v0.3.0，保留配置库、用户数据和自定义备份目录；本版没有格式迁移。
如需恢复配置内容，在「变更历史」核对备份涉及文件，先另存后续编辑，再明确确认恢复。备份可能包含原始凭据，请妥善保管。
导入来源 Agent 文件不变；导入到库后另行分发产生的写入，按对应 Agent 文件备份恢复。
