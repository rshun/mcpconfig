# MCP Hub v0.7.0

面向现代开发者桌面工作台（Workbench）标准全面升级前端体验与全生命周期能力：新增 JSON / JSONC / CLI 命令一键粘贴解析、打通按指定 Agent 安全移除 MCP 条目（无损保留注释与自动备份）、新增受控子进程 JSON-RPC 启动握手与工具发现自检、支持零密钥宿主环境变量就绪态指示、补齐启用/停用开关与自定义请求头认证可视化编辑，并消除多处对话框焦点与响应式细节毛刺。既有 `catalog.yaml`、`settings.json` 与客户端配置 100% 向后兼容。

## 本次变化

- **一键粘贴 JSON / 命令行智能解析（Paste-to-Configure）**：在添加/编辑 MCP 弹窗顶部新增配置片段智能识别面板，支持直接粘贴 Claude/Cursor/VSCode `mcpServers` JSON、OpenCode 带注释 `JSONC`、键值片段、`claude mcp add` 命令、带 `KEY=VAL` 环境变量前缀的 `npx`/`uvx` 启动命令及远程服务 URL，自动拆解参数数组并将各客户端环境变量写法归一化为 `${ENV:VAR}`。
- **按指定 Agent 安全移除与启停生命周期闭环**：全栈支持 `ChangeKind::Removed` 与 `PlanRequest.removals`，可在「我的 MCP」检查器或「Agents」页面将已安装条目加入待移除队列，走一次性 `previewId` 脱敏负向红字 Diff 预览、原文自动备份、JSONC/TOML/YAML 注释保留移除及 `managed-state.json` 托管键清理；编辑器新增「启用此 MCP」拨动开关，主列表新增分段状态胶囊筛选（全部 / 已分发 / 未分发 / 有差异）与 `已停用` 标记。
- **启动握手探测（`probe_entry`）与零密钥环境变量就绪灯**：检查器新增按需触发的「测试启动 / 校验配置」，对 `stdio` 服务拉起受控无窗口子进程（4 秒超时自动回收，隐藏凭据仅在 Rust 内存回填）执行 JSON-RPC 2.0 `initialize` + `tools/list` 握手并展示工具列表；`MatrixDto` 附带仅含布尔值的 `envStatus`，实时标出本机环境变量已就绪（绿灯）或未设置（黄标），绝不向前端暴露任何真实变量值。
- **技术透明度提升与高级字段可视化编辑**：主列表直接展示单行自适应截断的等宽命令/URL 胶囊，检查器提供命令卡片一键复制与「全选本机 Agent」快捷勾选；编辑器新增环境变量/请求头密码框明文切换图标按钮，并完整开放自定义请求头认证（`Auth::Header`：请求头名、前缀、凭据变量名）、`timeout_seconds` 超时秒数与 `tags` 分类标签。
- **桌面工作台细节打磨**：修复弹窗打开时默认聚焦右上角关闭按钮 `X` 导致突兀焦点框的问题；将「移除此 MCP」升级为行内二次确认条；在「软件设置 → 默认配置库文件」与「Agents」配置卡片补充目录定位与路径一键复制；当差异预览文件数不超过 2 个时自动展开 Diff 详情。

## 验证

测试、依赖恢复和构建在 GitHub Actions 执行：Windows/Linux Rust 测试、前端单元测试与真实浏览器 E2E 回归、Windows 桌面编译、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建、DMG 内应用签名校验，以及最终资产集合与校验清单检查。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版（macOS 用新 DMG 中的 **MCP Hub** 替换旧版本），或将 Windows GUI ZIP 解压到新目录运行。既有 `catalog.yaml`、`settings.json` 与 `managed-state.json` 无需迁移，直接兼容使用。
需要回退时重新安装 v0.6.0 即可。
