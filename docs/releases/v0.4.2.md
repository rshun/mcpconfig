# MCP Hub v0.4.2

优化已有配置查看、分发差异和 Agent 导入的脱敏规则：普通配置可以直接核对，只有识别到的凭据需要隐藏或映射。保留 Windows x64 GUI 免安装 ZIP，不迁移配置库或软件设置格式。

## 本次变化

- 普通 URL、包名、可执行文件路径、工作目录和参数正常显示；普通环境变量及请求头按原值保留。`MAX_TOKENS`、`--tokenizer` 等名称不作为 Token 凭据处理。
- `PASSWORD_FILE`、`TOKEN_PATH`、`--token-file` 等明确表示文件或目录的字段正常显示路径；值内另含可识别凭据时仍隐藏。
- 根据字段和参数语义识别密码、Token、API Key、Cookie、私钥和认证信息；覆盖敏感命令行选项、Java `-Dservice.password` / `-Dservice.apiKey` 属性、URL 认证部分及敏感查询参数、百分号编码和常见凭据格式。
- 原值和新值都需要隐藏时，差异仍标明“原值/新值”，实际分发使用真实配置，不把隐藏标记写入 Agent 文件。原有分发预览一致性保护继续保留。
- 导入普通配置无需环境变量映射，普通字段直接保存；识别到的敏感字面值仍需要映射，来源 Agent 文件保持不变。`--token=value` 保留选项名，只将值改为变量引用；已作为密码使用的参数整体映射，不保留其中的片段。
- 已有引用不读取环境值；混合字符串内的 `{env:VAR}`、`${env:VAR}`、`${VAR}` 也归一化为 `${ENV:VAR}`，内置上下文变量保留语义，便于跨 Agent 分发。
- 更新查看、预览、导入文案和使用说明。未新增或升级依赖。

## 验证与识别边界

测试、依赖恢复和构建全部在 GitHub Actions：Windows/Linux Rust、前端测试与浏览器回归、Windows 桌面编译和原生 DTO 测试、发布恢复与免安装打包测试、三平台 CLI 冒烟、Windows/macOS GUI 构建及最终资产集合与校验清单检查。
脱敏回归覆盖普通字段可读、敏感变更、URL 编码、参数角色、认证上下文、凭据文件路径、混合变量引用和真实导入落盘。本地不运行测试、构建或生成的应用。
ZIP 静态校验检查 x64 GUI 二进制、内容集合、CRC 和字节一致性，不等同于目标电脑启动或真实 MCP 连接验证。

规则根据名称、上下文和格式识别，无法可靠判断任意自定义名称下的任意裸字符串是否是密钥。
请使用明确的敏感字段或变量引用保存凭据；含凭据的 URL 或完整命令需要映射完整字段值。
导入不会创建环境变量或检查其实际值，后续分发前仍需核对运行环境。
具体边界见 [导入说明](https://github.com/rshun/mcpconfig/blob/v0.4.2/docs/IMPORTING.md) 和 [安全说明](https://github.com/rshun/mcpconfig/blob/v0.4.2/docs/SAFETY.md)。

检查通过后经 PR 合入 master，为已进入 master 历史且与主干文件树一致的精确候选提交创建标签，复用同一批已验证产物发布。
下载后使用 Windows `Get-FileHash -Algorithm SHA256 -LiteralPath '<downloaded-file>'` 核对清单；Linux/macOS 可使用 `sha256sum --check SHA256SUMS` 或 `shasum -a 256 -c SHA256SUMS`。

## 升级与回退

关闭旧程序后安装新版，或将 GUI ZIP 解压到新目录运行。保留配置库、用户 `.mcp-hub` 和自定义备份目录，本版没有格式迁移。
需要回退时关闭新版，运行旧目录或重新安装 v0.4.1；旧版会恢复较保守的展示和导入映射规则。
如需撤回导入内容，在“变更历史”核对配置库备份，先另存后续编辑，再明确确认恢复。备份可能包含历史凭据，请妥善保管。
